# Nova's game platform: how a round becomes play

This is the presentation layer for games. It sits on top of the curriculum, the trial builders and
the adaptive loop, and does not change them. A game's content (its rungs, trials and answers) comes
from the curriculum spec through `TrialFactory`. **How** that content is played comes from here.

```
curriculum spec -> TrialFactory -> Trial (content)          what to learn
Adaptive Engine -> SessionPlan (rung + scaffold)            how much help
ChoiceLook.of(game, place) + StoryScene(richness)           what it looks like
LevelScreen -> round view -> PlaySession -> GameRuntime     what happened
```

## The pieces

| Piece | File | What it decides |
|---|---|---|
| `ChoiceLook` | `app/lib/ui/play/stage/choice_look.dart` | The holder, the place colours and the ground patch for a game played in a given place. It is data: `byPlace` gives each place its holder, and `byGame` covers games whose story fixes the holder (the pattern train is always a train). |
| `Holder` | same file | Each holder is one kind of answer object: card, basket, balloon, bubble, lily pad, signpost, cloud, carriage or crystal. Each has its shape (aspect ratio and where the picture sits), how it arrives (pop, drop, rise, slide) and how it celebrates (lift or hop). |
| `HolderArt` | `stage/holders.dart` | Paints each holder with CustomPainters: what goes behind the picture, what goes in front (the basket weave, the bubble shine), and a glow. The picture always sits on a light face. |
| `ChoiceTrialView` / `ChoiceHolder` | `stage/choice_stage.dart` | The shared choice mechanic: arrival, idle bobbing, success, the try-again flow, first-step hints, the demonstration hand and semantics. |
| `PointingHand` | `stage/pointing_hand.dart` | The companion's helping hand. It points and taps, but never chooses for the child. |
| `TrialContext` | `trial_context.dart` | What each round view receives: `look`, `startHelp` (from the scaffold), `onResponse(correct, attempt:)` and `onMoment` (so the companion can take part). |
| `StoryScene(richness:)` | `ui/scene/story_scene.dart` | The place grows richer as the child moves up a game's levels: more flowers, then bunting and butterflies, then a rainbow. |
| `SoundEffects` / `Sfx` | `ui/audio/sound_effects.dart` | Optional sounds on their own players. The files are generated by `tools/sfx/generate_sfx.py`. |

## Play rules every choice game gets

- **Try again, never a dead end.**
  - A first miss makes that answer wobble and rest (faded, not choosable). The companion says
    "So close! Let's try another one." and gives a soft low sound, never a buzzer.
  - After a second miss, or when only the answer is left, the hand shows it and the child taps it.
  - Only the first try counts toward accuracy and stars. Later tries are logged as retries
    (`TrialSubmitted.attempt`), so the Adaptive Engine sees real independence.
- **Scaffolding you can see.** It follows `SessionPlan.scaffold`:

  | Scaffold | What the child sees |
  |---|---|
  | modelled | Every round opens with a demonstration: the hand shows the answer, and the companion looks at it and says "Watch me: I'd pick this one!" |
  | guided | The first round opens with a first step: one wrong answer floats away. |
  | hint on request | The first hint does a first step; the next one shows the answer. |
  | independent | Encouragement only. |

  All scaffold help counts as a hint in the session's signals.
- **Adaptation you can see.**
  - Moving up a rung makes the place richer (`richness` goes from 0 to 1 along the game's rungs).
  - Stepping back gives the rung's simpler task (fewer options) in the same place, so the goal
    stays the same.
- **Games in the place.** A journey activity plays in its stage's place (`LevelScreen.place`), so
  the same game looks different from stage to stage: word hunt uses signposts in Story Woods and
  bubbles in Memory Cove.
  - Choice rounds, memory pairs and light parades stand in the scene itself.
  - Rounds with small pieces (drag, sort, read, build) play on a mat tinted by the place.
- **The companion takes part.** It:
  - reacts to each answer;
  - cheers a run of three first-try answers ("You're on a roll!");
  - stays close after misses in a row ("I'm right here with you…");
  - looks toward the answer when it helps;
  - celebrates the end of the level, with warm praise for effort when the level was hard.
- **Accessibility.**
  - Every answer is a button with a name: its word or number, or "Choice n" for a picture.
  - A tried answer says so ("Already tried"), and a hidden answer leaves the semantics tree.
  - With reduced motion, nothing moves: arrivals, wobbles and the hand's tapping stop, and the
    game still plays.
  - Everything works right to left, and every sound has a visual counterpart.

## Adding a look

1. For a new place, add its holder to `ChoiceLook.byPlace`. A test checks that every place has its
   own holder.
2. For a game whose story needs a fixed holder, add it to `ChoiceLook.byGame`.
3. For a new holder, add it to `Holder` (with its aspect, face, arrival and lift) and to
   `_HolderPainter.paint`, keeping a light face behind the picture.

## Sounds

`python3 tools/sfx/generate_sfx.py` regenerates `app/assets/sfx/*.wav`:

| Sound | Meaning |
|---|---|
| tap, pop | Something was chosen, or a bubble or hint cleared an answer away. |
| success | A right answer. |
| retry | A gentle rising "hmm?" after a miss. |
| show | The companion's helping hand appears. |
| celebrate | The level is finished. |
| unlock | A new stage opens. |
| whoosh | Answers arrive. |

The sounds are synthesised in the script, so there are no licensing or download concerns. The
whole set is about 230 KB. Sound effects are silent unless the build's asset manifest lists them,
and a grown-up can turn them off in settings.

## Content decisions still open (copy_status: draft)

- **Arabic wording.** The new companion lines need specialist review. They avoid gendered
  imperatives by using "هيّا ن…" (let's), and none judges the child.
- **Retry thresholds.** Two tries before the answer is shown is a provisional choice, as is showing
  the first step (one wrong answer floats away) only when at least three answers remain.
- **Streak size.** The companion celebrates every run of three first-try answers.
- **Richness steps.** Bunting appears from a third of the way up a game's levels, and the rainbow
  from two-thirds.
